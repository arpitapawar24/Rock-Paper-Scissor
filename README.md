# Rock Paper Scissors Game ✊📄✂️

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.
This frontend project allows users to play against the computer with real-time score updates and dynamic game messages.

---

## 🚀 Features

* 🎮 Play Rock, Paper, Scissors against the computer
* 🧠 Random computer move generation
* 📊 Live score tracking
* 💬 Dynamic result messages (Win/Lose/Draw)
* 🎨 Responsive and user-friendly UI
* ⚡ Built completely with frontend technologies

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**

## 🎯 How the Game Works

* User selects:

  * Rock ✊
  * Paper 📄
  * Scissors ✂️

* Computer randomly selects one option.

* Winner is decided using standard rules:

  * Rock beats Scissors
  * Scissors beats Paper
  * Paper beats Rock

* Scores are updated automatically after each round.
